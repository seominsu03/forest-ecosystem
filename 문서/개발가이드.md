# 한국 숲 생태계 시뮬레이션 개발 가이드

프로젝트 소개, 구현 수치, 화면, 데이터 연결, 구조와 구현·테스트 계획을 이 문서에서 확인한다. 담당별 작업과 협업 규칙은 [역할분담.md](역할분담.md)를 따른다. 기존 11번 개발 착수 기준서의 수치를 구현 기준으로 채택했으며, 값을 조정할 때는 이 문서를 갱신한다.

## 프로젝트 소개

Processing Java Mode로 **2D 생태계 시뮬레이션**을 만든다. 동물이 스스로 이동하고 먹이를 찾으며, 포식·번식·사망을 거치면서 종별 개체 수가 어떻게 변하는지 관찰한다. 풀의 공급, 번식 간격, 초기 포식자 수, 재해가 먹이 관계와 장기 공존에 미치는 영향을 비교한다. 개체 수 급증과 멸종도 관찰 결과로 다룬다.

첫 생태계는 **한국 숲**으로 하고, 이후 같은 구조에 바다와 도시의 종과 환경 규칙을 추가할 수 있게 설계한다. 개발은 **생태 규칙 → 그래프와 먹이 피라미드 → 지도 조작·개체 정보·설정·재해** 순으로 나눠 진행한다.

현재는 2D 숲을 완성한다. 생태 계산은 지도 좌표와 시뮬레이션 시간으로 처리하고, 화면·카메라는 완료된 상태를 읽어 표시한다. 위치·이동속도·감지 거리·공격 거리에 화면 픽셀이나 확대 배율을 사용하지 않는다. 이후 같은 데이터를 활용하는 3D 관찰 화면을 확장할 수 있다.

## 기능 범위와 개발 순서

P1은 생태 규칙, P2는 관찰 화면, P3는 사용자 조작과 재해 개발 순서다. 세 단계 모두 숲 버전에 포함한다.

### P1. 생태 규칙

| ID | 기능 | 완료 기준 |
|---|---|---|
| F01 | **시간 진행과 초기 배치** | 일정한 시뮬레이션 단계마다 상태를 갱신한다. 기본 설정은 초식동물 4종 각 16마리, 삵·담비 각 4마리로 총 72마리다. 종별 암수는 반반이고, 새 실행마다 초기 배치를 무작위로 정한다. |
| F02 | **자율 이동과 감지** | 동물이 조금씩 방향을 바꾸며 탐색한다. 지도 격자로 주변 후보를 좁힌 뒤 거리와 전방 시야를 판정한다. 배가 부르면 이동속도와 움직이는 빈도가 줄어든다. |
| F03 | **풀 섭취와 재생** | 먹힌 풀은 사라지고, 일정 시간 뒤 무작위 위치에 다시 생긴다. 초식동물은 풀을 먹고, 포식자는 사냥감을 오래 발견하지 못하고 에너지가 낮을 때 풀을 보조 먹이로 이용한다. |
| F04 | **추격·도망·사냥** | 포식자는 지정된 먹잇감을 쫓고, 시야에서 놓치면 마지막 목격 지점으로 향한다. 초식동물은 포식자를 감지하면 도망친다. 포식자가 탈진하면 추격과 공격을 즉시 끝내며, 재추격 기준까지 회복한 뒤 다시 쫓을 수 있다. 공격으로 피해가 누적되고, 사냥이 성공하면 포식자가 에너지를 한 번에 얻는다. |
| F05 | **지구력·체력 회복** | 추격과 도망 중 지구력을 쓰고, 멈춰 쉴 때 회복한다. 에너지가 충분하면 휴식 중에 체력도 회복한다. |
| F06 | **번식과 사망** | 같은 종의 성체 암수가 만나 에너지와 대기 시간 조건을 충족하면 번식한다. 새끼의 성별은 50% 확률로 정한다. 포식이나 굶주림으로 체력이 0이 되거나 개별 수명에 도달하면 사망한다. |

### P2. 관찰과 시각화

| ID | 기능 | 완료 기준 |
|---|---|---|
| F07 | **개체 수 기록과 그래프** | 시작 시점과 출생·사망이 일어난 시뮬레이션 단계의 종별 개체 수를 기록한다. 여섯 종을 그래프에서 구분하고, 멸종한 종은 0마리로 표시한다. |
| F08 | **상세 먹이 피라미드** | 풀·초식동물·포식자의 현재 총수량을 층별로 보여주고, 층의 폭을 수량에 비례해 표시한다. |
| F09 | **작은 피라미드** | 지도 왼쪽 상단의 미니맵 자리에 세 층의 합계를 보여주는 작은 피라미드를 항상 표시한다. |

F07~F09는 같은 시뮬레이션 상태를 사용한다. 예를 들어 대륙밭쥐 한 마리가 태어나면 그래프의 대륙밭쥐 수와 두 피라미드의 초식동물 합계에 같은 변화가 반영된다.

### P3. 사용자 조작과 재해

| ID | 기능 | 완료 기준 |
|---|---|---|
| F10 | **지도 이동·확대·축소** | 기본 배율에서 보이는 영역보다 가로·세로 각각 2배인 숲을 마우스 드래그로 둘러보고, 휠로 확대·축소할 수 있다. |
| F11 | **개체 선택과 오른쪽 탭** | 동물을 클릭하면 능력치와 현재 상태를 볼 수 있다. 지도를 보면서 오른쪽 패널의 그래프·피라미드·개체 정보 탭을 전환할 수 있다. |
| F12 | **진행 조작** | 일시정지·재개·초기화와 0.5배·1배·3배속을 조작할 수 있다. 각 배속에서 시뮬레이션 하루는 현실 시간으로 60초·30초·10초다. |
| F13 | **실험 설정** | 시작 전에 삵과 담비의 수를 각각 짝수로 조절할 수 있다. 번식 빈도는 번식 간격을 바꿔 조절한다. 설정을 바꿔 실행하고 개체 수 그래프와 멸종 시점을 비교할 수 있다. |
| F14 | **재해 발생 판정** | 진행 중인 재해가 없으면 하루에 한 번 `없음 / 가뭄 / 산불`을 확률로 정한다. 재해는 한 번에 하나만 진행하며, 지속 시간은 종류별 범위에서 무작위로 정한다. |
| F15 | **가뭄과 산불의 영향** | 가뭄 중에는 풀의 재생이 늦어진다. 산불이 나면 해당 구역의 풀이 사라지고 그 안에 있는 동물의 체력이 줄어든다. |

## 1. 시간·지도·시작 조건

| 항목 | 개발 기준 |
|---|---|
| 개발 환경 | Processing Java Mode, 2D 한국 숲 |
| 시간 단계 | **시뮬레이션 0.05초마다 한 단계**. 600단계가 시뮬레이션 속 하루 |
| 배속 | **0.5배 / 1배 / 3배**. 현실 시간으로 하루에 각각 60초 / 30초 / 10초 |
| 지도 | **200 × 150 지도 단위**. 좌상단이 원점이고 오른쪽으로 갈수록 x, 아래로 갈수록 y가 증가 |
| 지도 경계 | 위치를 지도 안으로 보정하고, 닿은 변에서 이동 방향을 안쪽으로 반사 |
| 시작 개체 | 멧토끼·대륙밭쥐·노루·고라니 각 **16마리**, 삵·담비 각 **4마리**, 총 **72마리** |
| 시작 성별·나이 | 종마다 암수 반반. 초기 개체의 나이는 번식 가능 나이부터 개별 수명의 절반 사이에서 무작위로 배정 |
| 시작 상태 | 동물과 풀의 위치는 매 실행 무작위. 동물은 에너지 **70**, 지구력 **100**, 체력은 종별 최대치로 시작 |
| 풀 | **120개**로 시작. 먹힌 풀 한 개마다 재생 대기를 거쳐 무작위 위치에 한 개가 다시 생김. 기본 대기 시간은 **1일** |
| 주변 탐색 | **20 × 20 지도 단위** 격자를 사용. 후보를 찾은 뒤 실제 거리와 시야각을 확인 |

일시정지 중에는 시뮬레이션 시간과 재해 시간이 함께 멈춥니다. 지도 이동, 확대·축소, 탭 전환과 개체 확인은 화면에서 계속 처리합니다.

## 2. 종별 능력치와 먹이 관계

속도는 **시뮬레이션 1초당 지도 단위**, 시야각은 부채꼴의 **전체 각도**입니다. 나이·번식 간격·수명의 단위는 시뮬레이션 속 일입니다.

| 종 | 기본 / 질주 속도 | 감지 거리 / 시야각 | 최대 체력 | 번식 가능 나이 | 번식 대기 | 수명 범위 |
|---|---:|---:|---:|---:|---:|---:|
| 멧토끼 | 5.0 / 9.4 | 23 / 120° | 65 | 2일 | 3일 | 12~17일 |
| 대륙밭쥐 | 4.2 / 7.4 | 16 / 105° | 42 | 1일 | 2일 | 7~11일 |
| 노루 | 4.8 / 9.0 | 26 / 135° | 100 | 3일 | 4일 | 15~22일 |
| 고라니 | 4.5 / 8.1 | 21 / 120° | 118 | 3일 | 4일 | 14~20일 |
| 삵 | 5.2 / 10.2 | 25 / 105° | 82 | 3일 | 5일 | 13~19일 |
| 담비 | 5.0 / 9.6 | 23 / 110° | 94 | 3일 | 4일 | 12~18일 |

| 먹이 | 먹는 동물 | 섭취 한 번의 에너지 회복량 |
|---|---|---:|
| 풀 | 초식동물 4종 | +22 |
| 풀 | 삵·담비 | +8 |
| 대륙밭쥐 | 삵·담비 | +45 |
| 멧토끼 | 삵 | +55 |
| 노루 | 담비 | +75 |
| 고라니 | 담비 | +85 |

먹이 피라미드는 **풀 → 초식동물 → 포식자** 순으로 표시합니다. 포식자가 풀을 먹는 경우에도 삵과 담비는 포식자 층에 집계합니다.

### 종별 특성

| 단계 | 종 | 행동 설계의 의도 |
|---|---|---|
| 생산자 | 풀 | 초식동물의 주 먹이이자 포식자의 보조 먹이다. 섭취와 재생에 따라 지도에 있는 수량이 달라진다. |
| 초식동물 | 멧토끼 | 초식동물 중 가장 빠른 질주 속도로 삵의 추격을 피한다. |
| 초식동물 | 대륙밭쥐 | 체력과 시야가 작지만 성장과 번식이 빠르다. 삵과 담비가 공유하는 사냥감이다. |
| 초식동물 | 노루 | 감지 거리가 길고 시야각이 넓어 위협을 일찍 발견한다. |
| 초식동물 | 고라니 | 체력이 높아 공격을 여러 번 견딘다. |
| 포식자 | 삵 | 질주 속도로 대륙밭쥐와 멧토끼와의 거리를 좁힌다. |
| 포식자 | 담비 | 삵보다 한 번의 공격 피해가 크고 지구력 소모가 적다. 대륙밭쥐·노루·고라니를 사냥한다. |

## 3. 이동·사냥·휴식·번식 규칙

| 항목 | 첫 구현 기준 |
|---|---|
| **평상시 탐색** | 전진하며 **0.6초마다** 현재 방향에서 좌우 **25° 이내**로 무작위 회전. 먹이 후보가 여럿 보이면 가장 가까운 대상을 선택 |
| **포만** | 에너지 **85 이상**에서 평상시 이동속도를 기본값의 **60%**로 낮추고, **1초 이동·1초 정지**를 반복. 포식자는 에너지가 85 미만으로 내려가면 새 추격을 시작할 수 있음. 위협 회피는 포만 행동보다 우선 |
| **에너지** | 최대 **100**. 초당 초식동물 **0.8**, 포식자 **1.0** 소모. 에너지가 0인 동안 체력 **초당 3** 감소. 섭식으로 에너지가 생기면 굶주림 피해가 멈춤 |
| **풀 섭취** | 풀과의 거리가 **1.5 지도 단위 이하**면 섭취 가능. 포식자는 사냥감을 **6초 이상** 발견하지 못했고 에너지가 **30 이하**일 때 풀 탐색을 시작. 이후 사냥감이 다시 보이면 사냥으로 전환하고, 에너지 **85**에 도달하면 풀 탐색을 종료 |
| **추격과 공격** | 사냥감을 놓치면 마지막 목격 위치로 이동. 그 위치에 도착해도 찾지 못하면 탐색으로 복귀. 추격 중 거리 **2.5 이하**에서 공격. 한 번 공격하면 그 포식자는 **0.8초(16단계)** 뒤에 다시 공격할 수 있다. 거리 밖으로 나갔다 들어오거나 대상을 바꿔도 마지막 공격 시점부터 같은 대기 시간을 적용한다. 한 번의 피해량은 **삵 24, 담비 28** |
| **포식자의 추격 종료와 재개** | 포식자는 지구력이 **10 이하**가 되면 추격과 공격을 즉시 중단하고 휴식 조건을 확인한다. 지구력이 **60 이상**으로 회복되면 다시 추격할 수 있다. |
| **도망과 지구력** | 초식동물은 자신을 사냥할 수 있는 포식자를 감지하면 멀어지는 방향으로 질주. 시야에서 놓친 뒤에도 도망을 이어가며, 지구력 **10 이하**에서 질주를 멈춤. 위협이 보이고 지쳐 있으면 기본속도로 회피. 최대 지구력은 **100**, 질주 중 초당 **기본 18 / 삵 22 / 담비 16** 소모 |
| **휴식** | 추격·도망이 끝나고 위협이 보이지 않을 때, 회복 조건을 충족하면 휴식을 시작한다. 지구력이 **10 이하**이면 지구력 회복, 체력이 **최대치의 80% 이하**이고 에너지가 **55 이상**이면 체력 회복을 시작한다. 휴식 중 지구력은 **초당 20**, 에너지가 55 이상이면 체력은 **초당 2** 회복한다. 지구력 회복은 **60**에서, 체력 회복은 **최대치의 90%**에 도달하거나 에너지가 **55 미만**이 되면 완료 또는 중단한다. 두 목적이 모두 적용되면 남은 목적이 있을 동안 휴식을 이어간다. 위협을 감지하면 즉시 휴식을 중단한다. |
| **번식** | 같은 종의 성체 암수가 **3 지도 단위 이내**에 있고, 두 부모 모두 에너지 **75 이상**이며 번식 대기 시간이 끝났으면 새끼 한 마리 생성. 부모마다 에너지 **20** 소모 및 번식 대기 시간 적용. 새끼는 암수 각각 **50%**, 초기 에너지 **60**, 체력과 지구력은 최대치. 어미 근처 지도 안쪽에 배치 |
| **사망과 멸종** | 체력이 **0**이 되거나 개별 수명에 도달하면 사망. 사냥 에너지는 사망을 일으킨 공격의 포식자에게 한 번 지급. 멸종한 종은 그래프에 **0마리**로 남음. 모든 동물이 사라지면 실행을 종료하고 마지막 지도와 그래프를 열람할 수 있게 함 |

새끼는 태어날 때부터 성체와 같은 종별 능력치를 가지며, 번식 가능 나이에 도달한 뒤 번식한다. 개체 수는 먹이·번식·사망 규칙으로 변하도록 두고 고정 상한을 두지 않는다. 종이 멸종하면 자동 재도입 없이 0마리로 기록한다.

**한 단계 처리 순서**는 `시간·재해·풀 재생 → 주변 감지와 이동 → 섭식과 공격 → 에너지·체력 갱신 및 사망 → 생존 개체의 번식 → 통계 반영`입니다. 같은 풀을 여러 개체가 먹으려 하면 한 개체만 섭취합니다. 같은 단계의 출생·사망은 각각 기록하고, 그래프에는 그 단계가 끝난 뒤의 개체 수를 표시합니다.

## 6. A와 B의 연결 기준

공통 자료형은 ForestEcosystem/SharedTypes.pde에 정의한다. A는 완료된 단계의 상태와 사건을 전달하고 B는 읽어서 표시한다. Snapshot의 필드는 final이며, 목록과 개체 수는 생성 시 복사한다. 컬렉션은 읽기 전용으로 제공한다.

### 공통 enum

| 자료형 | 값 |
|---|---|
| Species | HARE(멧토끼), VOLE(대륙밭쥐), ROE_DEER(노루), WATER_DEER(고라니), LEOPARD_CAT(삵), MARTEN(담비) |
| Sex | MALE, FEMALE |
| AnimalState | WANDER, SEEK_FOOD, CHASE, ATTACK, FLEE, EAT, REST |
| SimulationState | READY, RUNNING, PAUSED, FINISHED |
| DisasterType | NONE, DROUGHT, WILDFIRE |
| PopulationEventType | BIRTH, DEATH |
| CommandType | START, PAUSE, RESUME, RESET, SET_SPEED |

### A가 B에게 전달하는 자료형

| 자료형 | 필드와 Java 자료형 |
|---|---|
| SimulationSnapshot | runId·step(long), state(SimulationState), speedMultiplier(double), mapWidth·mapHeight(float), animals(List<AnimalSnapshot>), plants(List<PlantSnapshot>), populationCounts(Map<Species, Integer>), activePlantCount(int), disaster(DisasterSnapshot) |
| AnimalSnapshot | id(long), species(Species), sex(Sex), state(AnimalState), x·y·directionRadians(float), health·maxHealth·energy·maxEnergy·stamina·maxStamina(float), ageSeconds·lifespanSeconds(double), baseSpeed·sprintSpeed·visionRange·visionAngleRadians(float) |
| PlantSnapshot | id(long), x·y(float), active(boolean) |
| PopulationInitialState | runId·step(long), populationCounts(Map<Species, Integer>),step은 생성 시 0으로 고정 |
| PopulationEvent | runId·eventId·step(long), species(Species), type(PopulationEventType) |

populationCounts는 내부적으로 EnumMap을 복사하고 외부에는 읽기 전용 Map으로 제공한다. 누락된 종은 0으로 채워 여섯 종 모두 포함한다. 그래프와 피라미드는 A가 집계한 수량을 사용한다.

PopulationEvent.delta()는 BIRTH에 +1, DEATH에 -1을 반환한다. B는 실행 ID와 사건 번호를 기준으로 중복 반영을 막는다. 같은 단계의 사건을 모두 반영한 뒤 그래프에 그 단계의 최종 개체 수를 표시한다.

### B가 A에게 전달하는 요청

| 자료형 | 필드와 Java 자료형 |
|---|---|
| StartSettings | initialLeopardCats·initialMartens(int), reproductionIntervalMultiplier(double) |
| SimulationRequest | type(CommandType), startSettings(StartSettings), speedMultiplier(double) |
| DisasterSnapshot | type(DisasterType), startStep·endStep(long), centerX·centerY·radius(float) |

SimulationRequest는 시작 설정을 받는 생성자로 START, 배속(double)을 받는 생성자로 SET_SPEED, CommandType을 받는 생성자로 PAUSE·RESUME·RESET을 만든다. START만 startSettings를 갖고 나머지 요청의 해당 필드는 null이다. speedMultiplier는 SET_SPEED에서 사용하며 다른 요청에서는 기본값 1.0이다. 실제 적용 가능 상태와 설정 범위는 A의 Simulation에서 검증한다.

B의 재해 판정기를 A가 시뮬레이션 단계에 맞춰 호출한다. NONE에는 산불 좌표와 기간을 0으로 전달하고, 산불의 구역 정보는 A와 B가 함께 사용한다. endStep에 도달하면 재해가 끝난다.

### 단위와 초기화

- step은 long이며 초기 단계는 0이다. 한 단계는 시뮬레이션 0.05초, 하루는 600단계다. SimulationSnapshot.simulationSeconds()는 step × 0.05를 반환한다.
- 나이와 개별 수명은 시뮬레이션 초(double)로 전달한다. 위치·거리는 지도 단위, 속도는 지도 단위/시뮬레이션 초다.
- 방향과 시야의 전체 각도는 라디안(float)이다. 오른쪽이 0이고 시계 방향이 양수다.
- 시작 대기에는 runId=0과 빈 동물·풀 목록, 여섯 종의 0마리 집계, NONE 재해를 사용한다. 시작할 때 새 실행 ID와 초기 기록을 생성한다.
- 배속은 double이며 0.5, 1.0, 3.0을 사용한다. 동물과 사건 ID는 실행 안에서 고유하다.
- 초기화하면 이전 실행 상태와 통계를 비우고 시작 대기로 돌아간다. 새 시작에서 B가 초기 기록을 받아 그래프를 초기화한다.

### 첫 연결 확인

대륙밭쥐 한 마리가 태어나면 종별 그래프는 16→17, 두 피라미드의 초식동물 합계는 64→65, 전체 동물은 72→73이 된다. 이후 초기화와 다시 시작을 확인한다.

화면 상단에는 진행 버튼·현재 날짜·재해 상태를 표시한다. 종별 표시 색을 그래프 범례에도 사용하고, 선택한 동물은 테두리로 구분한다. UI 구현 방식은 기본 도형과 버튼을 우선 검토하며, 슬라이더를 사용할 경우 ControlP5를 후보로 둔다.

## 8. 단계별 구현 계획

### 1단계 · 생태계가 스스로 움직이게 만들기

**대상 기능 F01~F06**

1. **시간과 초기 배치** — `Simulation`의 고정 시간 단계와 숲 설정을 구성한다. 풀과 동물 6종을 생성하고, 종별 초기 암수 비율을 맞춘다.
2. **이동과 주변 감지** — 처음부터 지도 격자를 사용한다. 탐색 이동, 전방 시야, 지도 경계 처리를 연결한다. 동물이 칸을 옮기거나 풀이 재생될 때 격자 목록도 갱신한다.
3. **먹이와 상호작용** — 풀 섭취·재생부터 연결하고, 사냥과 도망을 추가한다. 마지막 목격 지점 추격, 공격 피해 누적, 포만에 따른 감속, 지구력 소모와 휴식을 확인한다.
4. **번식과 사망** — 성체 암수의 번식 조건과 대기 시간, 새끼 생성, 포식·굶주림·자연사를 연결한다. 같은 단계에서 하나의 먹이 또는 사냥에 대한 에너지 지급이 한 번만 일어나도록 처리한다.

**완료 기준** — 기본 72마리로 숲이 자동으로 진행된다. 풀을 먹어 에너지를 얻는 장면, 사냥감을 놓친 포식자의 이동, 휴식 중 회복, 번식 조건에 따른 출생, 원인별 사망을 각각 확인할 수 있다.

### 2단계 · 개체 수 변화 보여주기

**대상 기능 F07~F09**

1. **개체 수 기록** — `PopulationHistory`에 시작 수량과 출생·사망 시점을 기록한다. 같은 단계에 여러 사건이 있으면 각 사건을 보관하고, 그래프에는 해당 단계의 최종 개체 수를 표시한다.
2. **종별 그래프** — 여섯 종을 구분하고, 멸종한 종의 선은 0마리로 이어서 표시한다.
3. **두 피라미드** — 상세 피라미드는 현재 수량에 비례해 층의 폭을 그린다. 지도 왼쪽 상단의 작은 피라미드는 세 층의 현재 합계를 표시한다.

**완료 기준** — 출생이나 사망이 일어나면 그래프의 해당 종 수와 두 피라미드의 집단 합계가 같은 시뮬레이션 상태를 반영한다. 예를 들어 대륙밭쥐가 한 마리 태어나면 그래프의 대륙밭쥐 수와 두 피라미드의 초식동물 합계가 각각 1씩 늘어난다.

### 3단계 · 조작, 설정, 재해 연결하기

**대상 기능 F10~F15**

1. **지도와 개체 선택** — 드래그 이동, 휠 확대·축소, 동물 클릭을 연결한다. 오른쪽 패널에 그래프·피라미드·개체 정보 탭을 배치한다. 지도를 움직이거나 확대해도 작은 피라미드는 지도 영역의 왼쪽 상단에 고정한다.
2. **진행과 실험 설정** — 일시정지·재개·초기화, 0.5배·1배·3배속을 연결한다. 시작 전 삵·담비의 개체 수를 짝수로 조절하고, 번식 간격 조절값을 정해진 적용 시점에 반영한다.
3. **가뭄과 산불** — 하루 단위 발생 판정, 재해 종류별 무작위 지속 시간, 가뭄의 풀 재생 지연, 산불 구역의 풀 소실과 체력 피해를 연결한다.
4. **통합 실행** — 기본 규모와 번식으로 개체 수가 늘어난 상황에서 1배속·3배속을 확인한다. 실행이 느려지면 격자 탐색, 통계 기록, 화면 그리기 중 어느 부분에 시간이 많이 드는지 측정한다.

**완료 기준** — 사용자가 초기 포식자 수나 번식 간격을 바꿔 실행하고, 지도에서 동물과 재해를 관찰하면서 개체 수 그래프를 확인할 수 있다. 일시정지·배속 변경·초기화 후에도 화면에 표시되는 수량이 현재 숲의 상태와 일치한다.

## 9. 테스트 및 균형 검증

### 1. 생태 규칙 테스트

동물의 위치·상태와 풀의 배치를 정해 둔 작은 장면에서 각 규칙을 확인한다. 결과가 예상과 다르면 같은 시작 상태와 난수 조건으로 다시 실행해 재현한다.

| 검증 항목 | 확인할 상황 | 통과 기준 |
|---|---|---|
| **초기화와 시간** | 기본 설정으로 시작한 뒤 일시정지·재개·배속 변경 | 총 72마리에서 시작하고 종별 암수가 반반이다. 정지 중에는 시뮬레이션 시간이 멈춘다. 같은 시작 상태에서 같은 시뮬레이션 단계까지 진행했을 때 배속별 생태계 결과가 일치한다. |
| **격자와 전방 시야** | 같은 거리의 대상을 동물 앞과 뒤에 두고, 시야가 격자 경계를 가로지르는 상황 확인 | 전방 시야 범위에 들어온 대상을 감지한다. 격자 탐색 결과가 검증용 전체 비교 결과와 일치한다. |
| **포만과 휴식** | 포만 기준 위아래의 개체를 비교하고, 체력 회복 중인 개체의 에너지를 55 미만으로 낮춤 | 포만 개체의 이동속도와 움직이는 빈도가 줄어든다. 에너지가 55 미만이면 체력 회복이 끝난다. 지구력 회복이 필요하면 휴식을 이어가고, 체력 회복만 하던 개체는 휴식을 끝낸다. |
| **추격과 도망** | 사냥감이 시야 밖으로 벗어나거나, 추격·도망 중 지구력이 기준 아래로 떨어지는 상황 확인 | 포식자는 마지막 목격 지점으로 향하고 다시 발견하면 추격을 이어간다. 지구력이 기준 아래로 떨어진 개체는 전력 질주를 멈춘다. |
| **포식자 탈진과 재추격** | 공격 대기 시간이 끝났고 사냥감이 공격 거리 안에 있는 상태에서, 포식자의 지구력이 개발 가이드의 탈진 기준에 도달하도록 함. 이후 지구력을 회복시킴 | 탈진한 단계부터 추격과 공격을 중단한다. 재추격 기준에 도달하기 전까지 추격을 멈춘 상태를 유지하며, 기준까지 회복하면 사냥감 감지 등 기존 추격 조건에 따라 다시 추격할 수 있다. |
| **풀과 보조 먹이** | 초식동물과 포식자의 풀 섭취, 풀 재생, 포식자가 풀을 찾는 조건 확인 | 먹힌 풀 한 개는 사라지고 대기 후 무작위 위치에 다시 생긴다. 포식자는 탐색 시간과 낮은 에너지 조건이 모두 맞을 때 풀을 찾고, 풀 한 개에서 얻는 에너지는 초식동물보다 적다. |
| **사냥과 사망** | 피해 누적, 굶주림, 자연사, 두 포식자의 동시 공격을 확인 | 공격과 굶주림은 해당 조건에서 체력을 줄인다. 체력 0 또는 개별 수명 도달 시 사망한다. 사냥감 한 마리의 사망과 사냥 에너지 지급은 각각 한 번만 처리된다. |
| **공격 대기 시간** | 공격 직후 포식자를 사냥 거리 밖으로 이동시켰다가 16단계 안에 다시 진입시킴 | 재진입이나 대상 변경 후에도 마지막 공격에서 16단계가 지나야 다시 공격할 수 있다. |
| **번식** | 번식 가능한 성체 암수와 에너지·나이·대기 시간 조건을 하나씩 바꾼 개체를 비교 | 같은 종의 성체 암수가 가까이 있고 모든 조건을 충족할 때 출생이 발생한다. 두 부모에게 대기 시간이 적용된다. 새끼 성별은 출생마다 50% 확률을 적용하므로, 소수의 출생 결과는 성비가 한쪽으로 치우칠 수 있다. |

### 2. 화면·조작·재해 통합 테스트

| 검증 항목 | 통과 기준 |
|---|---|
| **그래프와 피라미드** | 출생·사망 시점에 해당 종의 그래프가 갱신된다. 오른쪽 상세 피라미드와 지도 왼쪽 상단의 작은 피라미드가 같은 현재 수량을 표시한다. 멸종한 종은 그래프에서 0마리로 이어진다. |
| **카메라와 선택** | 드래그와 휠이 지도에 적용되고, 확대하거나 이동한 뒤 클릭해도 화면에서 가리킨 동물의 정보가 열린다. 작은 피라미드는 지도 왼쪽 상단에 고정된다. |
| **설정과 초기화** | 실행·일시정지·종료 상태에서 초기화하면 설정값은 보존되고 배속은 1배가 된다. 시작 대기에는 이전 실행 기록과 선택이 비워진다. 시작을 연속 입력해도 새 실행과 0단계의 초기 기록은 한 번만 생성되며, 입력한 포식자 수와 종별 암수 비율이 맞는다. |
| **재해 발생** | 판정 결과가 `없음 / 가뭄 / 산불`인 경우를 각각 확인한다. 새 재해는 하루 최대 한 번 시작하고, 이전 재해가 진행 중인 날의 판정은 건너뛴다. 지속 시간은 종류별 설정 범위 안에 들어간다. |
| **재해 효과** | 가뭄이 적용된 풀의 재생이 늦어진다. 산불은 해당 구역의 풀과 동물에 설정한 피해를 적용한다. 두 재해의 종료 후 상태도 확인한다. |

### 3. 생태계 균형 실험

**실험 규모** — 조건마다 무작위 초기 배치로 **3회씩, 시뮬레이션 속 30일**을 관찰한다. 3배속에서는 한 번에 현실 시간 약 5분이다. 비교할 때는 한 가지 설정을 바꾸고, 각 실행의 초기 배치와 실제 재해 발생도 결과에 함께 기록한다.

| 실험 | 바꿀 조건 | 관찰할 내용 |
|---|---|---|
| **기준 실행** | 기본 72마리와 기본 설정으로 시작 | 30일째 살아 있는 종, 종별 최대 개체 수, 멸종이 일어난 시점 |
| **초기 포식자 수 변경** | 예를 들어 삵을 4마리에서 6마리로 변경 | 삵의 먹이인 멧토끼와 대륙밭쥐가 어떻게 변하는지, 대륙밭쥐를 공유하는 담비도 영향을 받는지 확인 |
| **번식 간격 변경** | 기본값과 더 긴 번식 간격을 비교 | 먹이가 충분한 시기에 개체 수가 얼마나 빨리 늘고, 개체 수가 줄어든 뒤 얼마나 빨리 회복하는지 확인 |
| **풀 공급 감소** | 검증용 설정에서 풀 재생 대기 시간을 늘림 | 풀 수량이 줄어든 뒤 초식동물과 포식자가 어떤 순서로 반응하는지, 포식자의 풀 섭취가 얼마나 자주 일어나는지 확인 |

기본 설정에서 **여섯 종이 관찰 기간 끝까지 공존하는 실행 사례**를 찾는 것을 균형 조정 목표로 둔다. 특정 종이 여러 실행에서 초반에 사라지면, 그래프가 꺾이기 직전의 먹이량과 사망 원인을 확인한다. 굶주림이 반복되면 에너지 소모량이나 먹이 회복량을, 특정 포식자에게 집중적으로 잡히면 공격 피해나 추격 지속 시간을 **한 항목씩** 조정해 다시 비교한다.

### 4. 성능 확인

- **기본 72마리**와 **검증용 144마리**를 각각 1배속과 3배속에서 실행한다.
- 시뮬레이션 하루가 목표 시간에 가깝게 진행되는지, 지도 드래그와 탭 전환이 원활한지 확인한다.
- 느려지는 구간이 있으면 격자 탐색, 생태 규칙 갱신, 그래프 그리기에 걸리는 시간을 나눠 측정한다. 성능 통과 기준은 실제 실행 환경에서 측정한 뒤 정한다.


### 종별 균형 확인

대륙밭쥐는 두 포식자의 사냥과 빠른 번식의 영향을 함께 본다. 노루·고라니는 담비의 공격 기회와 체력 차이를, 삵·담비는 풀을 보조 먹이로 이용하는 빈도와 생존 기간을 확인한다. 자연사는 개별 수명과 초기 나이에 따라 시점이 분산되는지 확인한다.

### Processing 강의 활용

CH5의 조건문을 행동 판단에, CH8의 좌표 변환을 지도 조작에, CH11의 입력 이벤트를 선택과 드래그에 활용한다. CH16의 ControlP5는 UI 후보로 검토한다. 외부 이미지의 출처와 라이선스 파일을 보관한다.

수치 변경은 담당자 둘이 실행 결과를 보고 합의한 뒤 이 문서와 관련 테스트의 예상 결과에 함께 반영한다.
